The following workflow can be applied to quantify CD68,CD11c,and CD207 expressing cells within inner foreskin images.


Firstly ensure to install the SplineDist-main folder and the Image Analysis Workflow folder.
The SplineDist training dataset can be downloaded from the following public domain: https://zenodo.org/records/14898025



Instructions are located at the start of each folder within the Image Analysis Workflow for eeach step of Image Processing, Cell Counting, and Distance Analysis
